# Code of conduct

Stellome is a scientific project open to everyone. We expect contributors to:

- be respectful and constructive, in issues, pull requests and any other space linked to the project;
- assume good faith, and give and accept feedback on the work, never on the person;
- credit others' work and data sources accurately.

Harassment, discriminatory language and personal attacks are not tolerated. Maintainers may edit or remove contributions and block participants who break these rules.

To report a problem, open a private [security advisory](../../security/advisories/new) or contact the maintainer listed in `CITATION.cff`.

This code adapts the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.
